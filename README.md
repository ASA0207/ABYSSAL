# ABYSSAL · CELESTIAL SIGNATURE EDITION

기존 페이지의 모든 길드 정보, 문의 링크, Marian Hill — Down BGM을 유지한 프리미엄 업그레이드입니다.

## 새 기능
- 3D 느낌의 이중 궤도 시작 화면 + 52개 반짝이는 별
- 입장 시 워프/확산 연출, 음악/무음 입장
- 별빛 메시지 인터랙션 (5종)
- 길드 시그널 전송 애니메이션
- 클릭해서 열리는 비밀 편지
- 가입 여정 타임라인
- 마우스를 따라오는 은은한 조명
- 페이지 읽기 진행률 / 맨 위로 버튼
- 음악 재생 진행바 + 클릭 위치 탐색
- ASA 입력 시 초대형 감사 이스터에그
- 모바일 반응형 및 움직임 줄이기 설정 지원

## 설치
ZIP 내부의 파일/폴더 전체를 GitHub Pages 저장소 최상위에 업로드하세요. 기존 파일은 덮어쓰기 바랍니다.

## 유의
음악은 브라우저 정책상 입장 버튼을 눌러야 시작됩니다. 길드 정보는 기존 제공된 원본 그대로입니다.
